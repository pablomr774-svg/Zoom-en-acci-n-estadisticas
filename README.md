# Zoom en Acción | Estadísticas

Proyecto Next.js conectado a Supabase.

## Variables de entorno
En Vercel agrega:
- NEXT_PUBLIC_SUPABASE_URL = URL del proyecto Supabase
- NEXT_PUBLIC_SUPABASE_ANON_KEY = Publishable key (sb_publishable...)

> Aunque el nombre histórico de la variable dice ANON_KEY, con Supabase actual debes pegar ahí la Publishable key.

## Funciones
- Categorías dinámicas
- Equipos
- Jugadores
- Jornadas y partidos
- Resultados
- Asistencia / partidos jugados
- Goles
- Tabla general automática
- Top goleadores

La base de datos usada por esta versión coincide con las tablas creadas en el proyecto Supabase durante la configuración.
